Backrest Arch Designer

Design a symmetric arched top corner, then print a true-to-scale half-pattern to trace.

Above ~10" with foil cusps, a half may need the scaled/gridded fallback sheet instead of true 1:1 — the live "fits one sheet" check above will tell you.
Height is derived from width + spring angle for a true circular arc — it can't be set independently.
Derived height:
90° = semicircle · <90° = segmental · >90° = horseshoe / Moorish (true undercut)
0 = straight taper · 1 = deeply waisted/scooped
0 = straight taper to a point · 1 = elegant concave lancet point
Smaller = a tighter fiddlehead curl at the core
