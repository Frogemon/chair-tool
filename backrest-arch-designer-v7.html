Backrest Arch Designer

Design a symmetric arched top corner, then print a true-to-scale half-pattern to trace.

Capped at 10" so each half (with room for foil-cusp bulge) always prints true-to-scale on one 8.5×11 sheet — never the scaled/gridded fallback.
Height is derived from width + spring angle for a true circular arc — it can't be set independently.
Derived height:
90° = semicircle · <90° = segmental · >90° = horseshoe / Moorish (true undercut)

These are your two printable pages at 300 dpi — one full half-pattern each. Press and hold an image to save it to your photo library. If your browser doesn't offer a save option, take a screenshot instead — that always works.
